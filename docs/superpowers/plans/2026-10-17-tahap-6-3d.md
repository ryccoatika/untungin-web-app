# Phase 6 — 3D Visuals Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make Untungin feel alive without slowing it down. The plan adds:
- an interactive 3D hero on the landing page (profit bars that grow while coins drop in, tilting toward the pointer);
- a 3D profit chart on the dashboard with number labels and a 3D/2D switch;
- small celebrations when a store is created and when net profit first turns positive;
- a light 3D empty-state illustration.

Everything falls back to 2D or static when 3D isn't appropriate.

**Architecture:**
- Scene code is plain Three.js with no React. Each scene is a factory in `lib/three/scenes/*.ts` returning a `SceneController` (root object, camera, `update`, optional pointer/resize/done), so it can be unit-tested in Node.
- `components/three/three-canvas.tsx` owns the renderer:
  - pixel ratio capped at 2;
  - ResizeObserver;
  - a render loop paused when off-screen (IntersectionObserver) or when the tab is hidden;
  - disposal of everything on unmount.
- `useRenderMode()` decides `"3d"` or `"static"` from reduced motion, WebGL support and device strength (spec §7).
- Every 3D component sits behind `next/dynamic({ ssr: false })` and is rendered only in `"3d"` mode, so Three.js never loads on static devices or on form pages.

**Tech Stack:**
- Next.js 16.4 App Router and React 19.
- `three` 0.186 with `@types/three` 0.186 (new dependencies; spec §2).
- Tailwind 4, next-intl 4 and next-themes.
- Vitest (Three.js scene code runs in Node) and Playwright.

## Rulings

- **File names** follow the repo's kebab-case convention (`components/three/hero-scene.tsx`, not `HeroScene.tsx` as listed in spec §8).
- **The chart value** is each product's monthly contribution: Σ over its channels of (net price − material cost) × monthly sales estimate. That is what the product brings in before fixed costs, and it is the "contribution" of spec §7. Products without any sales estimate are left out. At most 8 bars: the 8 with the largest |value|, ordered by value (highest first).
- **Weak-device rule** is applied exactly as the spec says, even though some phones report ≤ 4 cores; they get the static versions.
- **Labels in 3D** are canvas-texture sprites (crisp, no DOM syncing). The 2D view and the product table remain the accessible representation; the 3D canvas has an `aria-label` that names the chart.
- **Moments:** "store created" uses a `?welcome=1` flag on the redirect from onboarding (removed from the address bar after it is read). "First profit" is remembered per store in `localStorage` (`untungin:first-profit:<storeId>`, try/catch); a different device may celebrate once more — acceptable.
- **3D empty states** appear only on non-form pages that have an empty state: `simulasi` and `analisis`. Form pages keep the plain `EmptyState`.
- **Chart view preference** (`3d`/`2d`) is stored in `localStorage` under `untungin:chart-view` (try/catch); static devices always see 2D and no switch.

```ts
export type RenderMode = "3d" | "static";

/** What the browser tells us; the two counts are missing in some browsers. */
export type DeviceSignals = {
  reducedMotion: boolean;
  webgl: boolean;
  hardwareConcurrency?: number;
  deviceMemory?: number;
};

/** Spec §7: ≤ 4 cores or ≤ 4 GB counts as a weak device. */
export const WEAK_DEVICE_LIMIT = 4;

export function chooseRenderMode(signals: DeviceSignals): RenderMode {
  if (signals.reducedMotion || !signals.webgl) return "static";
  if (signals.hardwareConcurrency !== undefined && signals.hardwareConcurrency <= WEAK_DEVICE_LIMIT) return "static";
  if (signals.deviceMemory !== undefined && signals.deviceMemory <= WEAK_DEVICE_LIMIT) return "static";
  return "3d";
}
```

`lib/three/dispose.ts`:

```ts
import type { BufferGeometry, Material, Object3D, Texture } from "three";

type Renderable = Object3D & { geometry?: BufferGeometry; material?: Material | Material[] };

/** Frees the GPU resources under `root`: each geometry, material and texture exactly once. */
export function disposeObject(root: Object3D): void {
  const geometries = new Set<BufferGeometry>();
  const materials = new Set<Material>();
  const textures = new Set<Texture>();

  root.traverse((object) => {
    const item = object as Renderable;
    if (item.geometry) geometries.add(item.geometry);
    const list = Array.isArray(item.material) ? item.material : item.material ? [item.material] : [];
    for (const material of list) materials.add(material);
  });
  for (const material of materials) {
    for (const value of Object.values(material)) {
      if (value && typeof value === "object" && (value as Texture).isTexture) textures.add(value as Texture);
    }
  }

  for (const geometry of geometries) geometry.dispose();
  for (const material of materials) material.dispose();
  for (const texture of textures) texture.dispose();
}
```

`lib/three/render-loop.ts`:

```ts
type Frame = (deltaSeconds: number, elapsedSeconds: number) => void;
type RequestFrame = (callback: (now: number) => void) => number;
type CancelFrame = (handle: number) => void;

/** Longest step one frame may take, so a tab coming back does not make animations jump. */
const MAX_DELTA = 0.1;

/**
 * requestAnimationFrame loop that runs only while started, on screen and in a visible tab
 * (spec §7). The host component feeds visibility from IntersectionObserver and visibilitychange.
 */
export class RenderLoop {
  private running = false;
  private visible = true;
  private pageVisible = true;
  private handle: number | null = null;
  private last = -1;
  private elapsed = 0;

  constructor(
    private readonly frame: Frame,
    private readonly raf: RequestFrame = (callback) => requestAnimationFrame(callback),
    private readonly caf: CancelFrame = (handle) => cancelAnimationFrame(handle),
  ) {}

  get active(): boolean {
    return this.handle !== null;
  }

  start() {
    this.running = true;
    this.sync();
  }

  stop() {
    this.running = false;
    this.sync();
  }

  setVisible(visible: boolean) {
    this.visible = visible;
    this.sync();
  }

  setPageVisible(visible: boolean) {
    this.pageVisible = visible;
    this.sync();
  }

  private sync() {
    const shouldRun = this.running && this.visible && this.pageVisible;
    if (shouldRun && this.handle === null) {
      this.last = -1;
      this.handle = this.raf(this.tick);
    } else if (!shouldRun && this.handle !== null) {
      this.caf(this.handle);
      this.handle = null;
    }
  }

  private tick = (now: number) => {
    const delta = this.last < 0 ? 0 : Math.min((now - this.last) / 1000, MAX_DELTA);
    this.last = now;
    this.elapsed += delta;
    this.handle = this.raf(this.tick);
    this.frame(delta, this.elapsed);
  };
}
```

```ts
"use client";

import { useSyncExternalStore } from "react";
import { chooseRenderMode, type RenderMode } from "@/lib/three/capability";

const REDUCED_MOTION = "(prefers-reduced-motion: reduce)";
let webglSupport: boolean | undefined;

export function hasWebGL(): boolean {
  if (webglSupport !== undefined) return webglSupport;
  try {
    const canvas = document.createElement("canvas");
    webglSupport = Boolean(canvas.getContext("webgl2") ?? canvas.getContext("webgl"));
  } catch {
    webglSupport = false;
  }
  return webglSupport;
}

function subscribe(onChange: () => void) {
  const query = window.matchMedia(REDUCED_MOTION);
  query.addEventListener("change", onChange);
  return () => query.removeEventListener("change", onChange);
}

function snapshot(): RenderMode {
  const nav = navigator as Navigator & { deviceMemory?: number };
  return chooseRenderMode({
    reducedMotion: window.matchMedia(REDUCED_MOTION).matches,
    webgl: hasWebGL(),
    hardwareConcurrency: nav.hardwareConcurrency || undefined,
    deviceMemory: nav.deviceMemory,
  });
}

/** "3d" or "static" in the browser (follows reduced-motion changes live); null on the server. */
export function useRenderMode(): RenderMode | null {
  return useSyncExternalStore(subscribe, snapshot, () => null);
}
```

```ts
import { CanvasTexture, SRGBColorSpace } from "three";
import type { LabelFactory } from "@/lib/three/scene";

const FONT_PX = 48;
const PADDING_PX = 18;

/** Draws `text` on a rounded pill and returns it as a texture (2× pixel density for crisp sprites). */
export const makeCanvasLabel: LabelFactory = (text, style) => {
  const canvas = document.createElement("canvas");
  const context = canvas.getContext("2d")!;
  const font = `600 ${FONT_PX}px ui-sans-serif, system-ui, sans-serif`;
  context.font = font;
  const width = Math.ceil(context.measureText(text).width) + PADDING_PX * 2;
  const height = FONT_PX + PADDING_PX * 2;
  canvas.width = width;
  canvas.height = height;
  context.font = font;
  context.fillStyle = style.background;
  context.beginPath();
  context.roundRect(0, 0, width, height, height / 2);
  context.fill();
  context.fillStyle = style.color;
  context.textBaseline = "middle";
  context.fillText(text, PADDING_PX, height / 2);
  const texture = new CanvasTexture(canvas);
  texture.colorSpace = SRGBColorSpace;
  return { texture, aspect: width / height };
};
```

```tsx
"use client";

import { useEffect, useRef } from "react";
import { Scene, WebGLRenderer } from "three";
import { disposeObject } from "@/lib/three/dispose";
import { RenderLoop } from "@/lib/three/render-loop";
import type { SceneController } from "@/lib/three/scene";
import { cn } from "@/lib/utils";

/** Spec §7: never render above 2× device pixels. */
const MAX_PIXEL_RATIO = 2;

type Props = {
  /** Called once on mount; remount with a `key` to rebuild the scene with new data. */
  create: () => SceneController;
  className?: string;
  /** Accessible name; omit together with `decorative` for purely decorative scenes. */
  label?: string;
  decorative?: boolean;
  interactive?: boolean;
  onDone?: () => void;
  /** WebGL failed (context creation or loss): the parent should show its static version. */
  onFail?: () => void;
};

export function ThreeCanvas({ create, className, label, decorative, interactive, onDone, onFail }: Props) {
  const hostRef = useRef<HTMLDivElement>(null);
  const callbacks = useRef({ create, onDone, onFail });
  callbacks.current = { create, onDone, onFail };

  useEffect(() => {
    const host = hostRef.current;
    if (!host) return;
    let renderer: WebGLRenderer;
    try {
      renderer = new WebGLRenderer({ antialias: true, alpha: true, powerPreference: "low-power" });
    } catch {
      callbacks.current.onFail?.();
      return;
    }
    renderer.setPixelRatio(Math.min(window.devicePixelRatio || 1, MAX_PIXEL_RATIO));
    renderer.domElement.style.display = "block";
    host.appendChild(renderer.domElement);

    const controller = callbacks.current.create();
    const scene = new Scene();
    scene.add(controller.root);

    const loop = new RenderLoop((delta, elapsed) => {
      controller.update(delta, elapsed);
      renderer.render(scene, controller.camera);
      if (controller.done?.()) {
        loop.stop();
        callbacks.current.onDone?.();
      }
    });

    const resize = () => {
      const width = host.clientWidth;
      const height = host.clientHeight;
      if (width === 0 || height === 0) return;
      renderer.setSize(width, height);
      controller.camera.aspect = width / height;
      controller.camera.updateProjectionMatrix();
      controller.resize?.(width, height);
    };
    resize();
    const resizeObserver = new ResizeObserver(resize);
    resizeObserver.observe(host);
    const intersectionObserver = new IntersectionObserver(([entry]) => loop.setVisible(entry.isIntersecting));
    intersectionObserver.observe(host);
    const onVisibility = () => loop.setPageVisible(document.visibilityState === "visible");
    document.addEventListener("visibilitychange", onVisibility);
    onVisibility();

    const onPointerMove = (event: PointerEvent) => {
      const rect = host.getBoundingClientRect();
      controller.setPointer?.(((event.clientX - rect.left) / rect.width) * 2 - 1, -(((event.clientY - rect.top) / rect.height) * 2 - 1));
    };
    const onPointerLeave = () => controller.setPointer?.(0, 0);
    if (interactive) {
      host.addEventListener("pointermove", onPointerMove);
      host.addEventListener("pointerleave", onPointerLeave);
    }
    const onContextLost = (event: Event) => {
      event.preventDefault();
      loop.stop();
      callbacks.current.onFail?.();
    };
    renderer.domElement.addEventListener("webglcontextlost", onContextLost);

    loop.start();

    return () => {
      loop.stop();
      resizeObserver.disconnect();
      intersectionObserver.disconnect();
      document.removeEventListener("visibilitychange", onVisibility);
      host.removeEventListener("pointermove", onPointerMove);
      host.removeEventListener("pointerleave", onPointerLeave);
      renderer.domElement.removeEventListener("webglcontextlost", onContextLost);
      scene.remove(controller.root);
      disposeObject(controller.root);
      renderer.dispose();
      renderer.forceContextLoss();
      renderer.domElement.remove();
    };
  }, [interactive]);

  return (
    <div
      ref={hostRef}
      className={cn("relative overflow-hidden", className)}
      role={decorative ? undefined : "img"}
      aria-label={decorative ? undefined : label}
      aria-hidden={decorative || undefined}
    />
  );
}
```

```ts
import {
  AmbientLight,
  BoxGeometry,
  CylinderGeometry,
  DirectionalLight,
  Group,
  MathUtils,
  Mesh,
  MeshStandardMaterial,
  PerspectiveCamera,
} from "three";
import type { Palette } from "../palette";
import type { SceneController } from "../scene";

/** Bar heights in scene units, rising left to right ("profit goes up"). */
export const HERO_BAR_HEIGHTS = [0.7, 1.15, 1.6, 2.2] as const;
export const HERO_COINS = 5;

const BAR_WIDTH = 0.62;
const BAR_GAP = 0.32;
const GROW_SECONDS = 1.1;
const GROW_STAGGER = 0.18;
const DROP_HEIGHT = 4.6;
const GRAVITY = 6;
const MAX_TILT_Y = 0.35;
const MAX_TILT_X = 0.12;

const easeOutCubic = (t: number) => 1 - (1 - t) ** 3;

/** Landing hero (user decision): bars grow, coins drop onto them, the group tilts toward the pointer. */
export function createHeroScene(palette: Palette): SceneController {
  const root = new Group();
  const camera = new PerspectiveCamera(35, 1, 0.1, 50);
  camera.position.set(0, 2.4, 8);
  camera.lookAt(0, 1.1, 0);

  const ambient = new AmbientLight(0xffffff, 1.4);
  const sun = new DirectionalLight(0xffffff, 2.2);
  sun.position.set(3, 6, 4);
  root.add(ambient, sun);

  const totalWidth = HERO_BAR_HEIGHTS.length * BAR_WIDTH + (HERO_BAR_HEIGHTS.length - 1) * BAR_GAP;
  const base = new Mesh(new BoxGeometry(totalWidth + 0.9, 0.12, 1.5), new MeshStandardMaterial({ color: palette.base }));
  base.position.y = -0.06;
  root.add(base);

  const barGeometry = new BoxGeometry(BAR_WIDTH, 1, BAR_WIDTH);
  barGeometry.translate(0, 0.5, 0); // grow from the floor: scale.y is the height
  const barMaterial = new MeshStandardMaterial({ color: palette.bar, roughness: 0.45 });
  const bars = HERO_BAR_HEIGHTS.map((_, i) => {
    const bar = new Mesh(barGeometry, barMaterial);
    bar.name = "bar";
    bar.position.x = -totalWidth / 2 + BAR_WIDTH / 2 + i * (BAR_WIDTH + BAR_GAP);
    bar.scale.y = 0.001;
    root.add(bar);
    return bar;
  });

  const coinGeometry = new CylinderGeometry(0.26, 0.26, 0.08, 32);
  const coinMaterials = [
    new MeshStandardMaterial({ color: palette.coinEdge, metalness: 0.6, roughness: 0.35 }),
    new MeshStandardMaterial({ color: palette.coin, metalness: 0.5, roughness: 0.3 }),
    new MeshStandardMaterial({ color: palette.coin, metalness: 0.5, roughness: 0.3 }),
  ];
  const coins = Array.from({ length: HERO_COINS }, (_, i) => {
    const coin = new Mesh(coinGeometry, coinMaterials);
    coin.name = "coin";
    coin.rotation.x = Math.PI / 2.4;
    root.add(coin);
    return { mesh: coin, bar: i % bars.length, velocity: 0, delay: i * 0.55, resting: 0 };
  });
  const placeAbove = (coin: (typeof coins)[number]) => {
    coin.mesh.position.set(bars[coin.bar].position.x, DROP_HEIGHT, 0);
    coin.velocity = 0;
    coin.resting = 0;
    coin.mesh.visible = false;
  };
  coins.forEach(placeAbove);

  let pointerX = 0;
  let pointerY = 0;

  return {
    root,
    camera,
    setPointer(x, y) {
      pointerX = MathUtils.clamp(x, -1, 1);
      pointerY = MathUtils.clamp(y, -1, 1);
    },
    update(delta, elapsed) {
      bars.forEach((bar, i) => {
        const progress = MathUtils.clamp((elapsed - i * GROW_STAGGER) / GROW_SECONDS, 0, 1);
        bar.scale.y = Math.max(0.001, HERO_BAR_HEIGHTS[i] * easeOutCubic(progress));
      });

      for (const coin of coins) {
        if (elapsed < coin.delay) continue;
        coin.mesh.visible = true;
        const top = bars[coin.bar].scale.y + 0.05;
        if (coin.resting > 0) {
          coin.resting += delta;
          if (coin.resting > 0.9) {
            coin.bar = (coin.bar + 1) % bars.length;
            placeAbove(coin);
          }
          continue;
        }
        coin.velocity += GRAVITY * delta;
        coin.mesh.position.y = Math.max(top, coin.mesh.position.y - coin.velocity * delta);
        coin.mesh.rotation.z += delta * 4;
        if (coin.mesh.position.y <= top) coin.resting = delta;
      }

      const sway = Math.sin(elapsed * 0.4) * 0.05;
      const damping = 1 - Math.exp(-delta * 4);
      root.rotation.y += (pointerX * MAX_TILT_Y + sway - root.rotation.y) * damping;
      root.rotation.x += (-pointerY * MAX_TILT_X - root.rotation.x) * damping;
    },
  };
}
```

```ts
/** Short Rupiah for chart labels: "Rp1,8 jt" (id), "Rp1.8M" (en). Same sign rules as formatRupiah. */
export function formatRupiahCompact(value: number, locale: AppLocale): string {
  const whole = Math.round(Math.abs(value));
  const amount = new Intl.NumberFormat(INTL_LOCALE[locale], { notation: "compact", maximumFractionDigits: 1 }).format(whole);
  const negative = value < 0 && /[1-9]/.test(amount);
  return `${negative ? "-" : ""}Rp${amount}`;
}
```

```ts
import { worstStatus, type LineStatus, type StoreAnalysis, type StoreData } from "@/lib/calc";

export type ChartBar = { productId: string; name: string; value: number; status: LineStatus };

/** More bars than this get unreadable on a phone. */
export const MAX_CHART_BARS = 8;

/**
 * Monthly contribution per product (spec §7 "profit/contribution bars"): Σ over its channels of
 * (net price − material cost) × monthly sales estimate. Products without any estimate are left out.
 * Keeps the MAX_CHART_BARS largest by size (losses count), ordered highest first.
 */
export function productChartData(analysis: StoreAnalysis, data: StoreData): ChartBar[] {
  const names = new Map(data.products.map((product) => [product.id, product.name]));
  const byProduct = new Map<string, { value: number; units: number; lines: { status: LineStatus }[] }>();
  for (const line of analysis.lines) {
    const entry = byProduct.get(line.productId) ?? { value: 0, units: 0, lines: [] };
    entry.value += line.contribution * line.estMonthlySales;
    entry.units += line.estMonthlySales;
    entry.lines.push(line);
    byProduct.set(line.productId, entry);
  }
  const bars: ChartBar[] = [];
  for (const [productId, entry] of byProduct) {
    if (entry.units <= 0) continue;
    bars.push({
      productId,
      name: names.get(productId) ?? "?",
      value: Math.round(entry.value) || 0,
      status: worstStatus(entry.lines) ?? "green",
    });
  }
  return bars
    .sort((a, b) => Math.abs(b.value) - Math.abs(a.value))
    .slice(0, MAX_CHART_BARS)
    .sort((a, b) => b.value - a.value);
}
```

```ts
import {
  AmbientLight,
  BoxGeometry,
  DirectionalLight,
  Group,
  MathUtils,
  Mesh,
  MeshStandardMaterial,
  PerspectiveCamera,
  Sprite,
  SpriteMaterial,
} from "three";
import type { LineStatus } from "@/lib/calc";
import type { Palette } from "../palette";
import type { LabelFactory, SceneController } from "../scene";

export type ChartSceneBar = { name: string; valueLabel: string; value: number; status: LineStatus };

export const NAME_LABEL_MAX = 14;
const MAX_HEIGHT = 2.4;
const BAR_WIDTH = 0.7;
const BAR_GAP = 0.45;
const LABEL_HEIGHT = 0.32;
const GROW_SECONDS = 0.9;

const easeOutCubic = (t: number) => 1 - (1 - t) ** 3;
const shorten = (name: string) => (name.length > NAME_LABEL_MAX ? `${name.slice(0, NAME_LABEL_MAX).trimEnd()}…` : name);

/** Bars per product (height ∝ monthly contribution, losses below the floor) with value and name labels. */
export function createProfitChartScene(bars: ChartSceneBar[], palette: Palette, makeLabel: LabelFactory): SceneController {
  const root = new Group();
  const camera = new PerspectiveCamera(35, 1, 0.1, 100);
  root.add(new AmbientLight(0xffffff, 1.5));
  const sun = new DirectionalLight(0xffffff, 2);
  sun.position.set(2, 6, 5);
  root.add(sun);

  const count = Math.max(bars.length, 1);
  const totalWidth = count * BAR_WIDTH + (count - 1) * BAR_GAP;
  const maxAbs = Math.max(...bars.map((bar) => Math.abs(bar.value)), 1);
  const hasLoss = bars.some((bar) => bar.value < 0);

  const floor = new Mesh(new BoxGeometry(totalWidth + 1, 0.04, 1.4), new MeshStandardMaterial({ color: palette.base }));
  floor.position.y = -0.02;
  root.add(floor);

  const geometry = new BoxGeometry(BAR_WIDTH, 1, BAR_WIDTH);
  geometry.translate(0, 0.5, 0); // scale.y is the signed height from the floor
  const colourFor: Record<LineStatus, number> = { green: palette.positive, yellow: palette.warning, red: palette.negative };
  const style = { color: palette.labelText, background: palette.labelBackground };

  const label = (text: string, x: number, y: number) => {
    const { texture, aspect } = makeLabel(text, style);
    const sprite = new Sprite(new SpriteMaterial({ map: texture, depthTest: false, transparent: true }));
    sprite.name = "chart-label";
    sprite.scale.set(LABEL_HEIGHT * aspect, LABEL_HEIGHT, 1);
    sprite.position.set(x, y, 0.5);
    sprite.renderOrder = 10;
    root.add(sprite);
    return sprite;
  };

  const items = bars.map((bar, i) => {
    const x = -totalWidth / 2 + BAR_WIDTH / 2 + i * (BAR_WIDTH + BAR_GAP);
    const target = (bar.value / maxAbs) * MAX_HEIGHT;
    const mesh = new Mesh(geometry, new MeshStandardMaterial({ color: colourFor[bar.status], roughness: 0.5 }));
    mesh.name = "chart-bar";
    mesh.position.x = x;
    mesh.scale.y = 0.001;
    root.add(mesh);
    const valueLabel = label(bar.valueLabel, x, 0);
    label(shorten(bar.name), x, hasLoss ? -MAX_HEIGHT - 0.35 : -0.35);
    return { mesh, target, valueLabel };
  });

  const fit = (aspect: number) => {
    const span = Math.max(totalWidth + 1.2, 4);
    const verticalSpan = (hasLoss ? MAX_HEIGHT * 2 : MAX_HEIGHT) + 1.4;
    const fov = MathUtils.degToRad(camera.fov);
    const distanceForWidth = span / 2 / Math.tan(fov / 2) / Math.max(aspect, 0.3);
    const distanceForHeight = verticalSpan / 2 / Math.tan(fov / 2);
    const distance = Math.max(distanceForWidth, distanceForHeight) * 1.05;
    const centreY = hasLoss ? 0 : MAX_HEIGHT / 2 - 0.2;
    camera.position.set(0, centreY + distance * 0.18, distance);
    camera.lookAt(0, centreY, 0);
  };
  fit(1.6);

  let pointerX = 0;
  return {
    root,
    camera,
    setPointer(x) {
      pointerX = MathUtils.clamp(x, -1, 1);
    },
    resize(width, height) {
      fit(width / height);
    },
    update(delta, elapsed) {
      const progress = easeOutCubic(MathUtils.clamp(elapsed / GROW_SECONDS, 0, 1));
      for (const item of items) {
        const height = item.target * progress;
        item.mesh.scale.y = Math.abs(height) < 0.001 ? 0.001 : height;
        item.valueLabel.position.y = height >= 0 ? height + 0.3 : height - 0.3;
      }
      const damping = 1 - Math.exp(-delta * 3);
      root.rotation.y += (pointerX * 0.25 - root.rotation.y) * damping;
    },
  };
}
```

```tsx
const STORAGE_KEY = "untungin:chart-view";
const VIEW_EVENT = "untungin:chart-view";

function readView(): View {
  try {
    return localStorage.getItem(STORAGE_KEY) === "2d" ? "2d" : "3d";
  } catch {
    return "3d";
  }

function saveView(view: View) {
  try {
    localStorage.setItem(STORAGE_KEY, view);
  } catch {
    // Private mode or blocked storage: the choice just isn't remembered.
  }
  window.dispatchEvent(new Event(VIEW_EVENT));
}

function subscribe(onChange: () => void) {
  window.addEventListener(VIEW_EVENT, onChange);
  window.addEventListener("storage", onChange);
  return () => {
    window.removeEventListener(VIEW_EVENT, onChange);
    window.removeEventListener("storage", onChange);
  };
```

```ts
import { AmbientLight, CylinderGeometry, DirectionalLight, Group, Mesh, MeshStandardMaterial, PerspectiveCamera, Vector3 } from "three";
import type { Palette } from "../palette";
import type { SceneController } from "../scene";

export const CELEBRATION_COINS = 36;
export const CELEBRATION_SECONDS = 2.6;
const GRAVITY = 9;

/** Small deterministic PRNG so tests (and the look) are repeatable. */
function mulberry32(seed: number) {
  let state = seed >>> 0;
  return () => {
    state = (state + 0x6d2b79f5) >>> 0;
    let t = state;
    t = Math.imul(t ^ (t >>> 15), t | 1);
    t ^= t + Math.imul(t ^ (t >>> 7), t | 61);
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
  };
}

/** A burst of coins from the bottom centre that falls away; done after CELEBRATION_SECONDS. */
export function createCelebrationScene(palette: Palette, seed = Date.now()): SceneController {
  const random = mulberry32(seed);
  const root = new Group();
  const camera = new PerspectiveCamera(45, 1, 0.1, 100);
  camera.position.set(0, 0, 12);
  root.add(new AmbientLight(0xffffff, 1.5));
  const sun = new DirectionalLight(0xffffff, 2.2);
  sun.position.set(2, 5, 6);
  root.add(sun);

  const geometry = new CylinderGeometry(0.32, 0.32, 0.09, 28);
  const materials = [
    new MeshStandardMaterial({ color: palette.coinEdge, metalness: 0.6, roughness: 0.35 }),
    new MeshStandardMaterial({ color: palette.coin, metalness: 0.5, roughness: 0.3 }),
    new MeshStandardMaterial({ color: palette.coin, metalness: 0.5, roughness: 0.3 }),
  ];
  const coins = Array.from({ length: CELEBRATION_COINS }, () => {
    const mesh = new Mesh(geometry, materials);
    mesh.name = "coin";
    mesh.position.set((random() - 0.5) * 2, -5, (random() - 0.5) * 2);
    const velocity = new Vector3((random() - 0.5) * 7, 9 + random() * 5, (random() - 0.5) * 3);
    const spin = new Vector3(random() * 8, random() * 8, random() * 8);
    root.add(mesh);
    return { mesh, velocity, spin };
  });

  let time = 0;
  return {
    root,
    camera,
    update(delta) {
      time += delta;
      for (const coin of coins) {
        coin.velocity.y -= GRAVITY * delta;
        coin.mesh.position.addScaledVector(coin.velocity, delta);
        coin.mesh.rotation.x += coin.spin.x * delta;
        coin.mesh.rotation.y += coin.spin.y * delta;
        coin.mesh.rotation.z += coin.spin.z * delta;
      }
    },
    done: () => time >= CELEBRATION_SECONDS,
  };
}
```

```ts
import { AmbientLight, BoxGeometry, CylinderGeometry, DirectionalLight, Group, Mesh, MeshStandardMaterial, PerspectiveCamera } from "three";
import type { Palette } from "../palette";
import type { SceneController } from "../scene";

/** Light empty-state picture: an empty tray with one coin bobbing above it. */
export function createEmptyScene(palette: Palette): SceneController {
  const root = new Group();
  const camera = new PerspectiveCamera(35, 1, 0.1, 50);
  camera.position.set(0, 1.8, 5);
  camera.lookAt(0, 0.4, 0);
  root.add(new AmbientLight(0xffffff, 1.5));
  const sun = new DirectionalLight(0xffffff, 2);
  sun.position.set(2, 5, 3);
  root.add(sun);

  const trayMaterial = new MeshStandardMaterial({ color: palette.base, roughness: 0.8 });
  const tray = new Group();
  const floor = new Mesh(new BoxGeometry(2, 0.08, 1.3), trayMaterial);
  const wall = new BoxGeometry(2, 0.3, 0.06);
  const side = new BoxGeometry(0.06, 0.3, 1.3);
  tray.add(floor);
  for (const [geometry, x, z] of [
    [wall, 0, 0.62],
    [wall, 0, -0.62],
    [side, 0.97, 0],
    [side, -0.97, 0],
  ] as const) {
    const mesh = new Mesh(geometry, trayMaterial);
    mesh.position.set(x, 0.15, z);
    tray.add(mesh);
  }
  root.add(tray);

  const coin = new Mesh(new CylinderGeometry(0.3, 0.3, 0.09, 32), [
    new MeshStandardMaterial({ color: palette.coinEdge, metalness: 0.6, roughness: 0.35 }),
    new MeshStandardMaterial({ color: palette.coin, metalness: 0.5, roughness: 0.3 }),
    new MeshStandardMaterial({ color: palette.coin, metalness: 0.5, roughness: 0.3 }),
  ]);
  coin.name = "coin";
  coin.rotation.x = Math.PI / 2;
  root.add(coin);

  return {
    root,
    camera,
    update(_delta, elapsed) {
      coin.position.y = 1 + Math.sin(elapsed * 2) * 0.15;
      coin.rotation.z = elapsed * 1.2;
      root.rotation.y = Math.sin(elapsed * 0.5) * 0.15;
    },
  };
}
```

```tsx
function wasCelebrated(storeId: string): boolean {
  try {
    return localStorage.getItem(firstProfitKey(storeId)) === "1";
  } catch {
    return true; // storage blocked: never risk celebrating on every visit
  }
}

function markCelebrated(storeId: string) {
  try {
    localStorage.setItem(firstProfitKey(storeId), "1");
  } catch {
    // Storage blocked: nothing to remember.
  }
}

/** Store-created and first-profit celebrations (spec §7): a dismissible message plus a 3D burst where allowed. */
export function Moments({ storeId, welcome, profitPositive }: { storeId: string; welcome: boolean; profitPositive: boolean }) {
  const t = useTranslations("Visuals");
  const mode = useRenderMode();
  const [moment, setMoment] = useState<Moment | null>(null);
  const [burst, setBurst] = useState(false);

  useEffect(() => {
    const next = momentToShow({ welcome, profitPositive, profitCelebrated: wasCelebrated(storeId) });
    if (welcome) {
      // Drop ?welcome=1 so a reload or a shared link does not celebrate again.
      const url = new URL(window.location.href);
      url.searchParams.delete("welcome");
      window.history.replaceState(window.history.state, "", url);
    }
    if (next === "firstProfit") markCelebrated(storeId);
    // eslint-disable-next-line react-hooks/set-state-in-effect -- reads localStorage once after mount
    setMoment(next);
    setBurst(next !== null);
  }, [storeId, welcome, profitPositive]);

  if (!moment) return null;
  return (
    <>
      <div role="status" className="flex items-start gap-3 rounded-lg border border-emerald-500/40 bg-emerald-500/10 p-4 text-sm">
        <p className="flex-1 font-medium">{t(moment)}</p>
        <button
          type="button"
          onClick={() => setMoment(null)}
          aria-label={t("dismiss")}
          className="-m-2 inline-flex size-10 shrink-0 items-center justify-center rounded-md hover:bg-emerald-500/15"
        >
          <X className="size-4" aria-hidden />
        </button>
      </div>
      {burst && mode === "3d" && <CelebrationBurst onDone={() => setBurst(false)} />}
    </>
  );
}
```

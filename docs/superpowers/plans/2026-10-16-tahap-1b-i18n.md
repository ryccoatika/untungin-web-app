# Phase 1b — i18n (Indonesian default + English) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every page is served under `/id/...` or `/en/...`, the locale is detected from the saved choice → browser language → `id`, all UI text comes from `messages/id.json` / `messages/en.json`, and users can switch language with an "ID | EN" toggle that is remembered (cookie + `profiles.locale`).

**Architecture:** `next-intl` v4 with prefix-based routing (`localePrefix: "always"`). All pages move into `app/[locale]/`, which becomes the root layout; `app/auth/callback` stays outside so the OAuth redirect URI is stable. `proxy.ts` first refreshes the Supabase session on the incoming request (so refreshed cookies reach Server Components), applies auth redirects on the locale-stripped path, then hands the request to the `next-intl` middleware and copies Supabase's cookies and no-store headers onto whatever response comes back. Zod schemas return message keys; Server Actions translate them.

**Tech Stack:** Next.js 16.4 App Router, `next-intl` ^4.14, `@supabase/ssr` 0.12, zod 4, Vitest 5, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-16-untungin-design.md` — §1 (Language row), §2, §3.1 (`profiles.locale`), §3.8 (grant), §5.1 (default channel name), §5.3, §5.4 (i18n), §8, §9 (i18n tests), §10 item 1b.

## Global Constraints

- Locales are exactly `["id", "en"]`; default `id`; `localePrefix: "always"`; locale cookie `NEXT_LOCALE` with `maxAge` one year (`60 * 60 * 24 * 365`).
- Detection order for an unprefixed path: cookie `NEXT_LOCALE` → `Accept-Language` → `id`. No other languages; anything else falls back to `id`.
- `app/auth/callback/route.ts` stays outside `app/[locale]/`.
- Indonesian copy must stay byte-identical to the current Phase 1 strings (existing e2e tests match them). English copy is given in this plan verbatim.
- After Task 4, no user-facing string is hardcoded in `app/` or `components/` except the brand name "Untungin" and the locale codes "ID"/"EN". Message catalogs `messages/id.json` and `messages/en.json` must always have identical key sets.
- Code comments, README, and docs are in English.
- Keep all existing security behavior: `safeNextPath` for every user-supplied redirect, `getClaims()` (never `getSession()`) on the server, Supabase no-store headers on responses that set auth cookies, RLS as the ownership boundary.
- Keep existing UI rules: `buttonVariants()` on `<Link>` (never `asChild`), native `<select>`, 40px tap targets, usable at 360px width with no horizontal scroll.
- Links and server redirects use the locale-aware helpers from `@/i18n/navigation` (`Link`, `redirect`, `usePathname`, `useRouter`), with unprefixed hrefs.
- Commit after every task with the message given. End every commit message with your harness Co-Authored-By trailer.

## Review Focus

1. **Auth cookies lost when the i18n middleware builds the response** (a token refresh during a request whose response is a next-intl redirect/rewrite) — the browser must still receive the refreshed Supabase cookies and the no-store headers. Pinned by `tests/unit/proxy-cookies.test.ts` (Task 1) and the "switching language keeps you signed in" e2e (Task 5).
2. **Locale-prefixed redirect targets** (`next=/en//evil.com`, saved-locale rewriting of `next`) — must stay same-origin and never produce a leading `//`. Pinned by `tests/unit/locale-paths.test.ts` (Task 1).
3. **Unknown or mis-cased locale segments** (`/fr/toko`, `/ID/toko`) — must render the 404 page, not crash or bypass auth. Pinned by `tests/e2e/i18n.spec.ts` (Task 1).
4. **Validation errors in English** (submitting a 100% margin on `/en/onboarding`) — the field error must be English, not Indonesian or a raw key. Pinned by `tests/e2e/i18n.spec.ts` (Task 5).
5. **English number formatting** (`12.5%` vs `12,5%`) — dashboard percentages follow the active locale. Pinned by `tests/unit/format.test.ts` (Task 4) and `tests/e2e/i18n.spec.ts` (Task 5).

Create `lib/i18n/paths.ts`:

```ts
import { routing, type AppLocale } from "@/i18n/routing";

function isAppLocale(value: string): value is AppLocale {
  return (routing.locales as readonly string[]).includes(value);
}

/** Splits "/en/s/x" into { locale: "en", rest: "/s/x" }; unprefixed paths get locale null. */
export function splitLocale(pathname: string): { locale: AppLocale | null; rest: string } {
  const [, first = "", ...tail] = pathname.split("/");
  if (!isAppLocale(first)) return { locale: null, rest: pathname };
  const rest = `/${tail.join("/")}`.replace(/\/+$/, "");
  return { locale: first, rest: rest === "" ? "/" : rest };
}

/** Puts `path` (which may carry ?query/#hash and an existing prefix) under `locale`. */
export function withLocale(path: string, locale: AppLocale): string {
  const cut = path.search(/[?#]/);
  const pathname = cut === -1 ? path : path.slice(0, cut);
  const suffix = cut === -1 ? "" : path.slice(cut);
  const { rest } = splitLocale(pathname || "/");
  return `${rest === "/" ? `/${locale}` : `/${locale}${rest}`}${suffix}`;
}
```

Replace `lib/supabase/proxy.ts`:

```ts
import { createServerClient, type CookieOptions } from "@supabase/ssr";
import type { NextRequest, NextResponse } from "next/server";
import type { Database } from "./database.types";

type CookieToSet = { name: string; value: string; options: CookieOptions };

/**
 * Collects the cookies and headers Supabase wants to set during a request.
 * Request cookies are updated immediately (so downstream Server Components see a
 * refreshed session); `apply` copies everything onto whatever response the proxy
 * finally returns (next, rewrite, or redirect).
 */
export function createCookieCollector(request: NextRequest) {
  const cookies: CookieToSet[] = [];
  const headers: Record<string, string> = {};

  return {
    setAll(cookiesToSet: CookieToSet[], cacheHeaders: Record<string, string>) {
      cookiesToSet.forEach(({ name, value }) => request.cookies.set(name, value));
      cookies.push(...cookiesToSet);
      Object.assign(headers, cacheHeaders);
    },
    apply<T extends NextResponse>(response: T): T {
      cookies.forEach(({ name, value, options }) => response.cookies.set(name, value, options));
      // Auth-cookie responses must not be cached by CDNs/proxies.
      Object.entries(headers).forEach(([key, value]) => response.headers.set(key, value));
      return response;
    },
  };
}

/** Refreshes the Supabase session for this request and reports whether a user is signed in. */
export async function refreshSession(request: NextRequest) {
  const collector = createCookieCollector(request);

  const supabase = createServerClient<Database>(
    process.env.NEXT_PUBLIC_SUPABASE_URL!,
    process.env.NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY!,
    {
      cookies: {
        getAll() {
          return request.cookies.getAll();
        },
        setAll(cookiesToSet, cacheHeaders) {
          collector.setAll(cookiesToSet, cacheHeaders);
        },
      },
    },
  );

  // Do not run code between createServerClient and getClaims().
  const { data } = await supabase.auth.getClaims();
  return { isLoggedIn: Boolean(data?.claims), apply: collector.apply };
}
```

If the installed `@supabase/ssr` types name the options type differently, use the type from its `setAll` signature (read `node_modules/@supabase/ssr/dist/main/types.d.ts`); do not use `any`.

Replace `proxy.ts`:

```ts
import createMiddleware from "next-intl/middleware";
import { NextResponse, type NextRequest } from "next/server";
import { routing } from "@/i18n/routing";
import { DEFAULT_AFTER_LOGIN, isProtectedPath } from "@/lib/auth/paths";
import { splitLocale } from "@/lib/i18n/paths";
import { refreshSession } from "@/lib/supabase/proxy";

const handleI18nRouting = createMiddleware(routing);

export async function proxy(request: NextRequest) {
  // Refresh first so the refreshed cookies are in `request` before next-intl copies its headers.
  const session = await refreshSession(request);
  const { pathname, search } = request.nextUrl;

  // The OAuth callback lives outside [locale] so its redirect URI never changes.
  if (pathname.startsWith("/auth/")) return session.apply(NextResponse.next({ request }));

  const { locale, rest } = splitLocale(pathname);
  if (locale) {
    if (!session.isLoggedIn && isProtectedPath(rest)) {
      const url = request.nextUrl.clone();
      url.pathname = `/${locale}/login`;
      url.search = `?next=${encodeURIComponent(pathname + search)}`;
      return session.apply(NextResponse.redirect(url));
    }
    if (session.isLoggedIn && rest === "/login") {
      const url = request.nextUrl.clone();
      url.pathname = `/${locale}${DEFAULT_AFTER_LOGIN}`;
      url.search = "";
      return session.apply(NextResponse.redirect(url));
    }
  }

  // Unprefixed paths are redirected by next-intl to the detected locale.
  return session.apply(handleI18nRouting(request));
}

export const config = {
  // All pathnames except Next internals, Vercel internals, and files with an extension.
  matcher: "/((?!api|_next|_vercel|.*\\..*).*)",
};
```

```sql
-- Saved UI language per user (null = not chosen yet) ----------------------
alter table public.profiles
  add column locale text check (locale in ('id', 'en'));

revoke update on public.profiles from authenticated;
grant update (full_name, locale) on public.profiles to authenticated;

-- create_store: the app passes the default channel name in the user's locale --
drop function public.create_store(text, text, integer, numeric, text);

create function public.create_store(
  p_name text,
  p_business_type text,
  p_operating_days integer,
  p_target_margin numeric,
  p_target_market text default null,
  p_default_channel_name text default 'Offline – Tunai'
)
returns uuid
language plpgsql
security invoker
set search_path = ''
as $$
declare
  v_store_id uuid;
begin
  if auth.uid() is null then
    raise exception 'not authenticated' using errcode = '42501';
  end if;

  insert into public.stores (owner_id, name, business_type, operating_days_per_month, target_margin_pct, target_market)
  values (auth.uid(), trim(p_name), p_business_type, p_operating_days, p_target_margin, p_target_market)
  returning id into v_store_id;

  insert into public.sales_channels (store_id, name, commission_pct, fixed_fee, sort_order)
  values (v_store_id, coalesce(nullif(trim(p_default_channel_name), ''), 'Offline – Tunai'), 0, 0, 0);

  return v_store_id;
end;
$$;

revoke execute on function public.create_store(text, text, integer, numeric, text, text) from public, anon;
grant execute on function public.create_store(text, text, integer, numeric, text, text) to authenticated;
```

/** Maps zod field errors (message keys) to translated messages. */
export function translateFieldErrors(
  fieldErrors: Record<string, string[] | undefined>,
  t: Translate,
): Record<string, string[] | undefined> {
  return Object.fromEntries(

import { getLocale, getTranslations } from "next-intl/server";
import { getValidationTranslator } from "@/lib/i18n/server";
import { translateFieldErrors } from "@/lib/i18n/translate";
import { DUPLICATE_STORE_NAME_KEY, storeInputSchema } from "@/lib/validation/store";

export async function createStoreAction(_prev: FormState, formData: FormData): Promise<FormState> {
  const values = rawValues(formData);
  const tValidation = await getValidationTranslator();
  const tStore = await getTranslations("Store");
  const parsed = storeInputSchema.safeParse(Object.fromEntries(formData));
  if (!parsed.success) {
    return { fieldErrors: translateFieldErrors(z.flattenError(parsed.error).fieldErrors, tValidation), values };
  }

  const { supabase, userId } = await requireUser();
  const [profile, stores] = await Promise.all([
    supabase.from("profiles").select("plan").eq("id", userId).single(),
    supabase.from("stores").select("id", { count: "exact", head: true }),
  ]);
  if (profile.error || stores.error) return { message: tStore("createFailed"), values };

  const plan = toPlan(profile.data?.plan);
  const limitMessage = tStore("limitReached", { max: PLAN_LIMITS[plan].maxStores });
  if (!canCreateStore(plan, stores.count ?? 0)) return { message: limitMessage, values };

  const input = parsed.data;
  const { data: storeId, error } = await supabase.rpc("create_store", {
    p_name: input.name,
    p_business_type: input.businessType,
    p_operating_days: input.operatingDaysPerMonth,
    p_target_margin: input.targetMarginPct,
    p_target_market: input.targetMarket ?? undefined,
    p_default_channel_name: tStore("defaultChannelName"),
  });

  if (error?.code === "23505") {
    return { fieldErrors: { name: [tValidation(DUPLICATE_STORE_NAME_KEY)] }, values };
  }
  if (error?.code === STORE_LIMIT_ERROR_CODE) return { message: limitMessage, values };
  if (error || !storeId) return { message: tStore("createFailed"), values };

  redirect({ href: `/s/${storeId}/dashboard`, locale: await getLocale() });
}

- [ ] **Step 3: Save action, saved-locale lookup, switcher**

Create `lib/i18n/save-locale.ts`:

```ts
"use server";

import { hasLocale } from "next-intl";
import { routing } from "@/i18n/routing";
import { createClient } from "@/lib/supabase/server";

/** Remembers the chosen UI language on the signed-in user's profile; no-op otherwise. */
export async function saveLocaleAction(locale: string): Promise<void> {
  if (!hasLocale(routing.locales, locale)) return;
  const supabase = await createClient();
  const { data } = await supabase.auth.getClaims();
  const userId = data?.claims?.sub;
  if (!userId) return;
  await supabase.from("profiles").update({ locale }).eq("id", userId);
}
```

Create `lib/i18n/saved-locale.ts`:

```ts
import "server-only";
import type { SupabaseClient } from "@supabase/supabase-js";
import { hasLocale } from "next-intl";
import { routing, type AppLocale } from "@/i18n/routing";
import type { Database } from "@/lib/supabase/database.types";

export async function getSavedLocale(
  supabase: SupabaseClient<Database>,
  userId: string,
): Promise<AppLocale | null> {
  const { data } = await supabase.from("profiles").select("locale").eq("id", userId).maybeSingle();
  return data?.locale && hasLocale(routing.locales, data.locale) ? data.locale : null;
}
```

Create `components/locale-switcher.tsx`:

```tsx
"use client";

import { useLocale, useTranslations } from "next-intl";
import { useTransition } from "react";
import { usePathname, useRouter } from "@/i18n/navigation";
import { routing, type AppLocale } from "@/i18n/routing";
import { saveLocaleAction } from "@/lib/i18n/save-locale";
import { cn } from "@/lib/utils";

export function LocaleSwitcher({ className }: { className?: string }) {
  const t = useTranslations("LocaleSwitcher");
  const locale = useLocale();
  const pathname = usePathname();
  const router = useRouter();
  const [pending, startTransition] = useTransition();

  function switchTo(next: AppLocale) {
    if (next === locale) return;
    startTransition(async () => {
      await saveLocaleAction(next);
      router.replace(`${pathname}${window.location.search}`, { locale: next });
    });
  }

  return (
    <div
      role="group"
      aria-label={t("label")}
      className={cn("inline-flex shrink-0 rounded-md border p-0.5 text-sm", className)}
    >
      {routing.locales.map((code) => (
        <button
          key={code}
          type="button"
          lang={code}
          aria-label={t(code)}
          aria-pressed={code === locale}
          disabled={pending}
          onClick={() => switchTo(code)}
          className={cn(
            "h-9 min-w-10 rounded px-2 font-medium",
            code === locale ? "bg-primary text-primary-foreground" : "text-muted-foreground",
          )}
        >
          {code.toUpperCase()}
        </button>
      ))}
    </div>
  );
}
```

(`redirect` here is `next/navigation`'s, because `next` is already a full same-origin path.)

`app/auth/callback/route.ts`:

```ts
import { NextResponse, type NextRequest } from "next/server";
import { DEFAULT_AFTER_LOGIN, safeNextPath } from "@/lib/auth/paths";
import { withLocale } from "@/lib/i18n/paths";
import { getSavedLocale } from "@/lib/i18n/saved-locale";
import { createClient } from "@/lib/supabase/server";

export async function GET(request: NextRequest) {
  const { searchParams, origin } = new URL(request.url);
  const code = searchParams.get("code");
  const next = safeNextPath(searchParams.get("next")) ?? DEFAULT_AFTER_LOGIN;

  if (code) {
    const supabase = await createClient();
    const { data, error } = await supabase.auth.exchangeCodeForSession(code);
    if (!error) {
      const saved = data.user ? await getSavedLocale(supabase, data.user.id) : null;
      return NextResponse.redirect(new URL(saved ? withLocale(next, saved) : next, origin));
    }
  }

  // Unprefixed; the proxy redirects to the detected locale.
  return NextResponse.redirect(new URL("/login?error=auth", origin));
}
```

## Translations

The UI is available in Indonesian (`id`, default) and English (`en`); every page lives under `/id/...` or `/en/...`.

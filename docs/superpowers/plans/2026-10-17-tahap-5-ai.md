# Phase 5 — AI Analysis Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A seller presses "Analisis usahaku" and gets plain-language advice from Gemini about their own numbers — what is good, what is wrong, what to try — with a "Coba di simulasi" button that opens each suggestion as a what-if scenario; results are kept as history and limited by a daily quota.

**Architecture:** Pure modules in `lib/ai/` build a compact, rounded snapshot of the store (`snapshot.ts`), hash it, describe and sanitise the model's JSON output (`output.ts`), and write the prompt (`prompt.ts`). `lib/ai/analyze.ts` runs the flow — cache check, quota claim, Gemini call, validation, save, refund on failure — with every side effect injected, so it is unit-tested with fakes. A Server Action wires the real dependencies: the user's Supabase client for reads, the secret-key client for the quota claim and the insert, and `lib/ai/gemini.ts` for the SDK call. Quota is counted in a new `ai_usage` ledger that survives store deletion and is claimed atomically by a database function.

**Tech Stack:** Next.js 16.4 App Router, React 19, TypeScript strict, Supabase (Postgres + RLS), `@google/genai` 2.30 (new dependency, spec §2), zod 4, next-intl 4, Vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-10-16-untungin-design.md` — §2 (AI row, `@google/genai`), §3.7 (`ai_analyses`), §3.8 (RLS for `ai_analyses`), §3.9 (AI analyses per day), §5.2 (`analisis` row), §5.4 (AI output in the active locale), §6 (AI feature), §9 (AI tests), §10 item 5.

**Base branch:** `feat/tahap-5-ai`, created from `feat/tahap-4-simulasi` (PR #4 not merged yet; "Coba di simulasi" needs the simulation page). When PR #4 merges, this branch's PR targets `master`.

## Review Focus

1. A model answer that is broken, partial, oversized or full of invented ids (unknown product/material/channel, prices out of range, extra fields) must never crash the page or create a broken simulation link: bad JSON fails the run without using quota, and unknown references only lose their link or chip. — Tests in Task 3 and Task 4.
2. Pressing the button twice, from two tabs, or at 23:59 WIB must never let a user exceed the daily quota or be charged for a failed or cached run. — Tests in Task 1 (atomic claim, day boundary) and Task 4 (refund, cache).
3. Old analyses must keep rendering after the data changes: a product deleted since the analysis loses its chip and "Coba di simulasi" button; the page says the analysis is from older data. — Tests in Task 3 and Task 5.
4. Deleting a store must not give the quota back, and one user can never read another user's analyses or usage. — Tests in Task 1.
5. The same unchanged data must not cost another analysis: the hash is stable across key order and float noise, and changes when a number the AI sees changes, or when the language changes. — Tests in Task 2 and Task 4.

## Rulings

- **Quota ledger:** a new `ai_usage` table (one row per analysis that reached Gemini, `user_id` → `profiles` on delete cascade, no `store_id`), so deleting a store does not reset the count (spec §6.1 step 2 note). `ai_analyses` keeps its cascade so a deleted store's data disappears.
- **Atomic claim:** `public.claim_ai_usage(p_user_id, p_since, p_limit)` locks the profile row, counts usage since `p_since`, inserts one row and returns its id (or null when used up). Executable only by `service_role`. The start of the WIB day is computed in TypeScript (`startOfJakartaDay`) so one unit-tested function owns the boundary; the limit comes from `lib/config/plans.ts`. A failed run deletes its usage row ("refund").
- **Cache first:** the cache check runs before the quota check — returning the unchanged result costs nothing, so a user with no quota left still gets it. The snapshot includes `locale`, so switching language produces a new analysis in that language.
- **Snapshot numbers are rounded** (Rupiah to whole numbers, percentages and months to 1 decimal) so float noise does not change the hash and the AI quotes clean numbers.
- **Output limits:** at most 8 highlights, issues and recommendations (extra items are dropped, not an error); text fields have generous maximum lengths (an over-long field fails validation).
- **References:** `related_product_ids` keep only active products of the store; a `change_price` simulation needs an existing price row for that product and channel (a new row would change no totals — Phase 4 finding); `change_material_price` needs a known material and −100…300%; `change_sales_volume` needs a multiplier 0…4 (the simulation URL's −100…300%); `new_price` must be a whole Rupiah 0…2.000.000.000. Anything else drops only that `simulation`. The same sanitising runs again when an old analysis is shown, against the current data.
- **Page:** latest result in full; up to 10 older ones as collapsible history; remaining quota ("Sisa kuota hari ini: 2 dari 3"); privacy note; a note when the data changed since the latest analysis. The button is disabled when no quota is left. Navigation: "Analisis AI" in the sidebar and on "Lainnya", plus an "Analisis usahaku" button on the dashboard when there is something to analyse.
- **No API key** → the action answers "Analisis AI belum disiapkan" without touching the quota. `/privasi` stays in Phase 7; the analysis page carries the privacy note now (spec §6.4).

```ts
const farPast = "2000-01-01T00:00:00.000Z";
const farFuture = "2999-01-01T00:00:00.000Z";

async function claim(userId: string, since = farPast, limit = 3) {
  const { data, error } = await admin.rpc("claim_ai_usage", { p_user_id: userId, p_since: since, p_limit: limit });

  return data as string | null;
}

async function usageCount(userId: string) {
  const { count, error } = await admin.from("ai_usage").select("*", { count: "exact", head: true }).eq("user_id", userId);
  if (error) throw error;
  return count ?? 0;
}

  let a: TestUser;
  let b: TestUser;

  beforeAll(async () => {
    a = await createTestUser("ai-a");
    b = await createTestUser("ai-b");
```

```sql
-- AI usage ledger (spec §6.1 step 2): one row per analysis that reached Gemini, counted per user per
-- Asia/Jakarta day. Kept apart from ai_analyses so deleting a store does not give the quota back.
create table public.ai_usage (
  id uuid primary key default gen_random_uuid(),
  user_id uuid not null references public.profiles (id) on delete cascade,
  created_at timestamptz not null default now()
);
create index ai_usage_user_created_idx on public.ai_usage (user_id, created_at);

alter table public.ai_usage enable row level security;
create policy ai_usage_select_own on public.ai_usage
  for select to authenticated using (user_id = auth.uid());

-- Takes one unit of quota atomically. p_since is the start of the user's day (lib/ai/quota.ts);
-- p_limit comes from lib/config/plans.ts. Returns the new usage id, or null when the quota is used up
-- or the user does not exist. Only the server calls it, with the secret key.
create function public.claim_ai_usage(p_user_id uuid, p_since timestamptz, p_limit integer)
returns uuid
language plpgsql
security definer
set search_path = ''
as $$
declare
  v_count integer;
  v_id uuid;
begin
  -- Lock the profile row so concurrent claims for one user serialize.
  perform 1 from public.profiles where id = p_user_id for update;
  if not found then
    return null;
  end if;

  select count(*) into v_count
  from public.ai_usage
  where user_id = p_user_id and created_at >= p_since;
  if v_count >= p_limit then
    return null;
  end if;

  insert into public.ai_usage (user_id) values (p_user_id) returning id into v_id;
  return v_id;
end;
$$;

revoke execute on function public.claim_ai_usage(uuid, timestamptz, integer) from public, anon, authenticated;
grant execute on function public.claim_ai_usage(uuid, timestamptz, integer) to service_role;
```

```ts
const HOUR_MS = 60 * 60 * 1000;
const DAY_MS = 24 * HOUR_MS;
/** Asia/Jakarta (WIB) is UTC+7 all year; there is no daylight saving. */
const WIB_OFFSET_MS = 7 * HOUR_MS;

/** Start of the quota day (00:00 WIB, spec §6.1) that contains `now`. */
export function startOfJakartaDay(now: Date): Date {
  const local = now.getTime() + WIB_OFFSET_MS;
  const localMidnight = local - (((local % DAY_MS) + DAY_MS) % DAY_MS);
  return new Date(localMidnight - WIB_OFFSET_MS);
}

export function remainingQuota(limit: number, used: number): number {
  return Math.max(0, limit - used);
}
```

```ts
/** Whole Rupiah; `|| 0` turns -0 into 0. */
const rupiah = (value: number) => Math.round(value) || 0;
/** One decimal, for percentages, months and quantities. */
const oneDecimal = (value: number) => Math.round(value * 10) / 10 || 0;
const maybe = <T>(value: T | null, round: (v: T) => number) => (value === null ? null : round(value));

export function buildSnapshot(
  data: StoreData,
  analysis: StoreAnalysis,
  info: SnapshotStoreInfo,
  locale: AppLocale,
): AnalysisSnapshot {
  const byCategory: Partial<Record<ExpenseCategory, number>> = {};
  for (const expense of data.expenses) {
    byCategory[expense.category] = (byCategory[expense.category] ?? 0) + monthlyAmount(expense, data.store.operatingDaysPerMonth);
  }
  for (const category of Object.keys(byCategory) as ExpenseCategory[]) {
    byCategory[category] = rupiah(byCategory[category]!);
  }

  return {
    locale,
    store: {
      name: data.store.name,
      businessType: info.businessType,
      targetMarket: info.targetMarket,
      targetMarginPct: oneDecimal(data.store.targetMarginPct),
      operatingDaysPerMonth: data.store.operatingDaysPerMonth,
    },
    channels: data.channels.map((channel) => ({
      id: channel.id,
      name: channel.name,
      commissionPct: oneDecimal(channel.commissionPct),
      fixedFee: rupiah(channel.fixedFee),
    })),
    materials: data.materials.map((material) => ({
      id: material.id,
      name: material.name,
      category: material.category,
      purchaseQty: oneDecimal(material.purchaseQty),
      purchaseUnit: material.purchaseUnit,
      purchasePrice: rupiah(material.purchasePrice),
      wastePct: oneDecimal(material.wastePct),
    })),
    products: data.products
      .filter((product) => product.isActive)
      .map((product) => ({
        id: product.id,
        name: product.name,
        lines: analysis.lines
          .filter((line) => line.productId === product.id)
          .map((line) => ({
            channelId: line.channelId,
            price: rupiah(line.price),
            competitorPrice: maybe(line.competitorPrice, rupiah),
            estMonthlySales: oneDecimal(line.estMonthlySales),
            materialCost: rupiah(line.materialCost),
            fullCost: maybe(line.fullCost, rupiah),
            netPrice: rupiah(line.netPrice),
            contribution: rupiah(line.contribution),
            marginPct: maybe(line.marginPct, oneDecimal),
            targetMarginPct: oneDecimal(line.targetMarginPct),
            status: line.status,
          })),
      })),
    totals: {
      grossRevenue: rupiah(analysis.grossRevenue),
      netRevenue: rupiah(analysis.netRevenue),
      materialCosts: rupiah(analysis.materialCosts),
      netProfit: rupiah(analysis.netProfit),
      netMarginPct: maybe(analysis.netMarginPct, oneDecimal),
      totalUnits: oneDecimal(analysis.totalUnits),
      fixedCosts: {
        byCategory,
        depreciation: rupiah(analysis.fixedCosts.depreciation),
        total: rupiah(analysis.fixedCosts.total),
      },
      bepUnitsMonthly: analysis.bepUnitsMonthly,
      bepUnitsDaily: analysis.bepUnitsDaily,
      totalCapital: rupiah(analysis.totalCapital),
      // Without assets there is nothing to pay back (the dashboard shows "—" too).
      paybackMonths: analysis.totalCapital > 0 ? maybe(analysis.paybackMonths, oneDecimal) : null,
    },
    warnings: analysis.warnings.map((warning) => ({
      code: warning.code,
      lines: warning.lines.map((line) => ({ productId: line.productId, channelId: line.channelId })),
    })),
  };
}

/** JSON with object keys sorted at every level, so equal data always gives equal text. */
export function canonicalJson(value: unknown): string {
  if (Array.isArray(value)) return `[${value.map(canonicalJson).join(",")}]`;
  if (value !== null && typeof value === "object") {
    const entries = Object.entries(value as Record<string, unknown>)
      .filter(([, v]) => v !== undefined)
      .sort(([a], [b]) => (a < b ? -1 : a > b ? 1 : 0));
    return `{${entries.map(([k, v]) => `${JSON.stringify(k)}:${canonicalJson(v)}`).join(",")}}`;
  }
  return JSON.stringify(value);
}

export function snapshotHash(snapshot: AnalysisSnapshot): string {
  return createHash("sha256").update(canonicalJson(snapshot)).digest("hex");
}
```

```ts
import { z } from "zod";
import { priceKey, type Overrides, type StoreData } from "@/lib/calc";
import { overridesToSearchParams, SIMULATION_LIMITS } from "@/lib/simulation/query";
import type { AnalysisSnapshot } from "./snapshot";

export const PRIORITIES = ["tinggi", "sedang", "rendah"] as const;
export type Priority = (typeof PRIORITIES)[number];

/** Extra list items are dropped (not an error) so one chatty answer still shows. */
export const MAX_ITEMS = 8;
/** −100…300% in the simulation URL is a sales multiplier of 0…4. */
const MAX_SALES_MULTIPLIER = 1 + SIMULATION_LIMITS.maxPct / 100;

const text = (max: number) => z.string().trim().min(1).max(max);
const list = <T extends z.ZodType>(item: T) => z.array(item).transform((items) => items.slice(0, MAX_ITEMS));

const simulationSchema = z.discriminatedUnion("type", [
  z.object({
    type: z.literal("change_price"),
    product_id: z.string(),
    channel_id: z.string(),
    new_price: z.number().int().min(0).max(SIMULATION_LIMITS.maxPrice),
  }),
  z.object({
    type: z.literal("change_material_price"),
    material_id: z.string(),
    pct: z.number().min(SIMULATION_LIMITS.minPct).max(SIMULATION_LIMITS.maxPct),
  }),
  z.object({
    type: z.literal("change_sales_volume"),
    multiplier: z.number().min(0).max(MAX_SALES_MULTIPLIER),
  }),
]);
export type AiSimulation = z.infer<typeof simulationSchema>;

const issueSchema = z.object({
  title: text(200),
  explanation: text(1000),
  related_product_ids: z.array(z.string()),
  priority: z.enum(PRIORITIES),
});

// A bad simulation only loses the link, never the advice: it is checked separately below.
const recommendationSchema = z.object({ action: text(300), reason: text(1000), simulation: z.unknown().optional() });

const outputSchema = z.object({
  summary: text(2000),
  highlights: list(text(500)),
  issues: list(issueSchema),
  recommendations: list(recommendationSchema),
});

export type AnalysisOutput = {
  summary: string;
  highlights: string[];
  issues: { title: string; explanation: string; related_product_ids: string[]; priority: Priority }[];
  recommendations: { action: string; reason: string; simulation?: AiSimulation }[];
};

/** JSON Schema sent to Gemini as `responseJsonSchema` (spec §6.2). zod above is the real check. */
export const ANALYSIS_RESPONSE_SCHEMA = {
  type: "object",
  properties: {
    summary: { type: "string", description: "2 to 4 sentences." },
    highlights: { type: "array", items: { type: "string" }, maxItems: MAX_ITEMS },
    issues: {
      type: "array",
      maxItems: MAX_ITEMS,
      items: {
        type: "object",
        properties: {
          title: { type: "string" },
          explanation: { type: "string" },
          related_product_ids: { type: "array", items: { type: "string" } },
          priority: { type: "string", enum: [...PRIORITIES] },
        },
        required: ["title", "explanation", "related_product_ids", "priority"],
      },
    },
    recommendations: {
      type: "array",
      maxItems: MAX_ITEMS,
      items: {
        type: "object",
        properties: {
          action: { type: "string" },
          reason: { type: "string" },
          simulation: {
            anyOf: [
              {
                type: "object",
                properties: {
                  type: { type: "string", enum: ["change_price"] },
                  product_id: { type: "string" },
                  channel_id: { type: "string" },
                  new_price: { type: "integer" },
                },
                required: ["type", "product_id", "channel_id", "new_price"],
              },
              {
                type: "object",
                properties: {
                  type: { type: "string", enum: ["change_material_price"] },
                  material_id: { type: "string" },
                  pct: { type: "number" },
                },
                required: ["type", "material_id", "pct"],
              },
              {
                type: "object",
                properties: {
                  type: { type: "string", enum: ["change_sales_volume"] },
                  multiplier: { type: "number" },
                },
                required: ["type", "multiplier"],
              },
              { type: "null" },
            ],
          },
        },
        required: ["action", "reason"],
      },
    },
  },
  required: ["summary", "highlights", "issues", "recommendations"],
} as const;

/** Ids an answer may point at. A price line is "productId:channelId" with a saved price. */
export type KnownRefs = { productIds: Set<string>; materialIds: Set<string>; priceLines: Set<string> };

export function refsFromSnapshot(snapshot: AnalysisSnapshot): KnownRefs {
  return {
    productIds: new Set(snapshot.products.map((product) => product.id)),
    materialIds: new Set(snapshot.materials.map((material) => material.id)),
    priceLines: new Set(snapshot.products.flatMap((product) => product.lines.map((line) => priceKey(product.id, line.channelId)))),
  };
}

/** The same check against today's data, for analyses saved earlier. */
export function refsFromStoreData(data: StoreData): KnownRefs {
  const active = new Set(data.products.filter((product) => product.isActive).map((product) => product.id));
  const channels = new Set(data.channels.map((channel) => channel.id));
  return {
    productIds: active,
    materialIds: new Set(data.materials.map((material) => material.id)),
    priceLines: new Set(
      data.prices
        .filter((row) => active.has(row.productId) && channels.has(row.channelId))
        .map((row) => priceKey(row.productId, row.channelId)),
    ),
  };
}

function knownSimulation(raw: unknown, refs: KnownRefs): AiSimulation | undefined {
  const parsed = simulationSchema.safeParse(raw);
  if (!parsed.success) return undefined;
  const simulation = parsed.data;
  switch (simulation.type) {
    case "change_price":
      return refs.priceLines.has(priceKey(simulation.product_id, simulation.channel_id)) ? simulation : undefined;
    case "change_material_price":
      return refs.materialIds.has(simulation.material_id) ? simulation : undefined;
    case "change_sales_volume":
      return simulation;
  }
}

/**
 * Validates a model answer (or a saved one) and drops what points at unknown data: product ids leave
 * the issue, a bad simulation leaves the recommendation (the advice stays). Null when the shape is wrong.
 */
export function sanitizeOutput(raw: unknown, refs: KnownRefs): AnalysisOutput | null {
  const parsed = outputSchema.safeParse(raw);
  if (!parsed.success) return null;
  const { summary, highlights, issues, recommendations } = parsed.data;
  return {
    summary,
    highlights,
    issues: issues.map((issue) => ({
      ...issue,
      related_product_ids: [...new Set(issue.related_product_ids)].filter((id) => refs.productIds.has(id)),
    })),
    recommendations: recommendations.map(({ action, reason, simulation }) => {
      const known = knownSimulation(simulation, refs);
      return known ? { action, reason, simulation: known } : { action, reason };
    }),
  };
}

function toOverrides(simulation: AiSimulation): Overrides {
  switch (simulation.type) {
    case "change_price":
      return { prices: { [priceKey(simulation.product_id, simulation.channel_id)]: simulation.new_price } };
    case "change_material_price":
      return { materialPricePct: { [simulation.material_id]: simulation.pct } };
    case "change_sales_volume":
      return { salesMultiplier: simulation.multiplier };
  }
}

/** "Coba di simulasi" target (spec §6.2): the Phase 4 URL format. */
export function simulationHref(storeId: string, simulation: AiSimulation): string {
  return `/s/${storeId}/simulasi?${overridesToSearchParams(toOverrides(simulation))}`;
}
```

```ts
import { ANALYSIS_RESPONSE_SCHEMA, refsFromSnapshot, sanitizeOutput, type AnalysisOutput } from "./output";
import { systemInstruction, userPrompt } from "./prompt";
import { snapshotHash, type AnalysisSnapshot } from "./snapshot";

/** One structured-output call to the model; resolves to the raw JSON text. */
export type GenerateJson = (request: { system: string; prompt: string; schema: object }) => Promise<string>;

export type AnalyzeDeps = {
  /** snapshot_hash of this store's latest analysis, or null. */
  latestHash: () => Promise<string | null>;
  /** Takes one unit of today's quota; the usage id, or null when it is used up. */
  claimUsage: () => Promise<string | null>;
  refundUsage: (usageId: string) => Promise<void>;
  generate: GenerateJson;
  save: (row: { snapshotHash: string; snapshot: AnalysisSnapshot; output: AnalysisOutput }) => Promise<void>;
};

export type AnalyzeStatus = "created" | "cached" | "quota" | "failed";

/**
 * Spec §6.1 steps 2–7. The cache check comes first because an unchanged result costs nothing.
 * Any failure after the claim gives the quota back; nothing is saved.
 */
export async function runAnalysis(deps: AnalyzeDeps, snapshot: AnalysisSnapshot): Promise<AnalyzeStatus> {
  const hash = snapshotHash(snapshot);
  let usageId: string | null;
  try {
    if ((await deps.latestHash()) === hash) return "cached";
    usageId = await deps.claimUsage();
  } catch (error) {
    logFailure("before the AI call", error);
    return "failed";
  }
  if (!usageId) return "quota";

  try {
    const text = await deps.generate({
      system: systemInstruction(snapshot.locale),
      prompt: userPrompt(snapshot),
      schema: ANALYSIS_RESPONSE_SCHEMA,
    });
    const output = sanitizeOutput(JSON.parse(text), refsFromSnapshot(snapshot));
    if (!output) throw new Error("The AI answer does not match the output schema");
    await deps.save({ snapshotHash: hash, snapshot, output });
    return "created";
  } catch (error) {
    logFailure("during the AI call", error);
    await deps.refundUsage(usageId).catch((refundError) => logFailure("refunding the quota", refundError));
    return "failed";
  }
}

/** Logs only the error message: the snapshot and the answer hold the seller's data. */
function logFailure(stage: string, error: unknown) {
  console.error(`AI analysis failed ${stage}: ${error instanceof Error ? error.message : String(error)}`);
}
```

```ts
import { GoogleGenAI } from "@google/genai";
import type { GenerateJson } from "./analyze";

/** Spec §2: Gemini 3.5 Flash-Lite (stable; ai.google.dev/gemini-api/docs/models, checked 2026-10-17). */
export const DEFAULT_GEMINI_MODEL = "gemini-3.5-flash-lite";
/** Spec §6.1 step 5. */
export const AI_TIMEOUT_MS = 30_000;

export function geminiModel(): string {
  return process.env.GEMINI_MODEL?.trim() || DEFAULT_GEMINI_MODEL;
}

export function createGeminiGenerate(apiKey: string, model: string): GenerateJson {
  const ai = new GoogleGenAI({ apiKey });
  return async ({ system, prompt, schema }) => {
    const response = await ai.models.generateContent({
      model,
      contents: prompt,
      config: {
        systemInstruction: system,
        responseMimeType: "application/json",
        responseJsonSchema: schema,
        abortSignal: AbortSignal.timeout(AI_TIMEOUT_MS),
        // One attempt only: retries would run past the 30-second limit.
        httpOptions: { timeout: AI_TIMEOUT_MS, retryOptions: { attempts: 1 } },
      },
    });
    const text = response.text;
    if (!text) throw new Error("Gemini returned no text");
    return text;
  };
}
```

```ts
/** Newest first. RLS limits it to stores the signed-in user owns. */
export async function listAnalyses(supabase: SupabaseClient<Database>, storeId: string, limit: number): Promise<StoredAnalysis[]> {
  const { data, error } = await supabase
    .from("ai_analyses")
    .select("id, created_at, snapshot_hash, output")
    .eq("store_id", storeId)
    .order("created_at", { ascending: false })
    .limit(limit);
  if (error) throw error;
  return (data ?? []).map((row) => ({ id: row.id, createdAt: row.created_at, snapshotHash: row.snapshot_hash, output: row.output }));
}

/** The signed-in user's analyses since `since` (RLS: own rows only), for the quota shown on the page. */
export async function countUsageSince(supabase: SupabaseClient<Database>, since: Date): Promise<number> {
  const { count, error } = await supabase
    .from("ai_usage")
    .select("id", { count: "exact", head: true })
    .gte("created_at", since.toISOString());
  if (error) throw error;
  return count ?? 0;
```

```ts
"use server";

import { getLocale, getTranslations } from "next-intl/server";
import type { AppLocale } from "@/i18n/routing";
import { runAnalysis, type AnalyzeStatus } from "@/lib/ai/analyze";
import { createGeminiGenerate, geminiModel } from "@/lib/ai/gemini";
import { startOfJakartaDay } from "@/lib/ai/quota";
import { buildSnapshot } from "@/lib/ai/snapshot";
import { requireUser } from "@/lib/auth/require-user";
import { tryAnalyzeStore } from "@/lib/calc";
import { PLAN_LIMITS, toPlan } from "@/lib/config/plans";
import { listAnalyses } from "@/lib/data/analyses";
import { loadStoreData } from "@/lib/data/load-store-data";
import { revalidateStore } from "@/lib/data/revalidate";
import { getStore } from "@/lib/data/stores";
import { createAdminClient } from "@/lib/supabase/admin";
import type { Json } from "@/lib/supabase/database.types";
import { isUuid } from "@/lib/uuid";

export type AnalyzeState = { status: AnalyzeStatus | "notConfigured" | "unavailable"; message: string } | undefined;

export async function analyzeStoreAction(storeId: string, _prev: AnalyzeState): Promise<AnalyzeState> {
  const t = await getTranslations("Analysis.result");
  const unavailable = { status: "unavailable", message: t("unavailable") } as const;
  if (!isUuid(storeId)) return unavailable;

  const { supabase, userId } = await requireUser();
  // Loading with the user's client proves ownership (RLS) before any secret-key call.
  const [store, data] = await Promise.all([getStore(storeId), loadStoreData(storeId)]);
  if (!store || !data) return unavailable;
  const { analysis } = tryAnalyzeStore(data);
  if (!analysis || analysis.lines.length === 0) return unavailable;

  const apiKey = process.env.GEMINI_API_KEY?.trim();
  if (!apiKey) return { status: "notConfigured", message: t("notConfigured") };

  const locale = (await getLocale()) as AppLocale;
  const snapshot = buildSnapshot(data, analysis, { businessType: store.business_type, targetMarket: store.target_market }, locale);
  const { data: profile } = await supabase.from("profiles").select("plan").eq("id", userId).maybeSingle();
  const limit = PLAN_LIMITS[toPlan(profile?.plan)].aiAnalysesPerDay;
  const admin = createAdminClient();
  const model = geminiModel();

  const status = await runAnalysis(
    {
      latestHash: async () => (await listAnalyses(supabase, storeId, 1))[0]?.snapshotHash ?? null,
      claimUsage: async () => {
        const { data: usageId, error } = await admin.rpc("claim_ai_usage", {
          p_user_id: userId,
          p_since: startOfJakartaDay(new Date()).toISOString(),
          p_limit: limit,
        });
        if (error) throw error;
        return usageId;
      },
      refundUsage: async (usageId) => {
        const { error } = await admin.from("ai_usage").delete().eq("id", usageId);
        if (error) throw error;
      },
      generate: createGeminiGenerate(apiKey, model),
      save: async ({ snapshotHash, snapshot: input, output }) => {
        const { error } = await admin.from("ai_analyses").insert({
          store_id: storeId,
          user_id: userId,
          model,
          snapshot_hash: snapshotHash,
          input_snapshot: input as unknown as Json,
          output: output as unknown as Json,
        });
        if (error) throw error;
      },
    },
    snapshot,
  );

  if (status === "created") revalidateStore();
  return { status, message: t(status) };
}
```

```ts
/** The auth user id for an e2e email, read with the admin API. */
export async function userIdByEmail(email: string): Promise<string> {
  const { data, error } = await adminClient().auth.admin.listUsers({ perPage: 1000 });
  if (error) throw error;
  const user = data.users.find((candidate) => candidate.email === email);
  if (!user) throw new Error(`No user ${email}`);
  return user.id;
}

/** The id of the store currently open in `page`. */
export function storeIdFromUrl(page: Page): string {
  const match = page.url().match(/\/s\/([0-9a-f-]{36})\//);
  if (!match) throw new Error(`Not on a store page: ${page.url()}`);
  return match[1];
}
```
